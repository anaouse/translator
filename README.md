# 声明

本项目是仅供个人学习与日常使用的小翻译器

# 使用说明

在 release 下载 exe 后双击运行，在托盘会显示一个图标，右键图标可以退出。

## 翻译窗口

输入和翻译结果共用一个窗口，顶部始终显示输入框和发音按钮。

- `Alt+Q`：打开翻译窗口，自动聚焦输入框。输入中文或英文，按 `Enter` 翻译。
- `Alt+A`：翻译选中的文本；没有选中文本时，打开同一个翻译窗口并聚焦输入框。
- 双击或鼠标拖动选中文本后，也可以点击悬浮小球翻译。
- 按 `Enter` 后窗口不隐藏，下方先显示“请求翻译中...”，随后显示翻译结果，可以继续修改输入并再次翻译。
- 点击 🔊 朗读当前提交的原文：英文读英文，中文读中文。中文发音需要系统安装中文语音。
- 选词翻译后，焦点默认在结果区。输入框没有焦点时，按任意键隐藏窗口；点击输入框后可以正常输入。
- 按 `Esc` 或点击窗口外部也可以隐藏窗口。
