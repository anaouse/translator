# 说明

现在alt+q的时候会跳出一个输入窗口，这时候输入中文或英文可以发出申请翻译然后展示结果，但是我发现这样设计其实不好。

因为没有必要，只需要保留翻译窗口一个窗口就行了，在header加入一个输入框即可，目前的header是英翻译中的时候有一个小喇叭，中翻译英则没有，所以要求header常驻，小喇叭也一直在，中译英的时候发音中文就好。

- 只保留一个窗口，就是包含翻译结果的那个窗口，要alt+q的时候也展示那个窗口，然后自动聚焦输入栏，回车的时候不隐藏窗口，下方窗口自动变为“请求翻译中...”然后得到结果再展示
- 我觉得alt+a没选中好像也会跳出那个现在的输入窗口，没必要，把相关的代码删除了，现在只需要一个窗口，包含翻译结果，输入窗口，发声喇叭，alt+a选中没有东西也保留弹出窗口
- 总翻译窗口出现的时候，如果输入栏没有被聚焦，这时候说明是选中单词后翻译，这时候用户点击任意的键盘按键它都直接隐藏。
